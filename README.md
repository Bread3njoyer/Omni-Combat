# Omni-Combat
Website can be found at: https://bread3njoyer.github.io/Omni-Combat/

The design is simple, using only vanilla HTML, CSS, and JavaScript to accomplish the tasks.

# Gameplay
Pick one of three classes to play from, one of three maps to play in, and one of three difficulties to play on.
Face off against deadly monsters, move around the board, and defeat your opponents swiftly.
